# My Portfolio

A stunning portfolio website built with React, Tailwind CSS, and Framer Motion.

## Structure

The project follows a component-based architecture:

- `src/components`: Reusable UI components
- `src/sections`: Main sections of the landing page
- `src/utils`: Helper functions and animations
- `src/data`: Content data

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
